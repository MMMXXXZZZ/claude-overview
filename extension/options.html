Claude Overview

Replaces Google's AI Overview with an answer from Claude.

Off by default. With it on, each query also carries your local time, time zone, Google country and the locality Google shows in the page footer, so Claude can answer “near me”, “open now” and “today” properly. Exact coordinates are included only if you have already granted google.com location access — this never raises a permission prompt of its own, and rounds to about 110 m. It travels in the message, after the prompt-cache breakpoint, so it costs nothing in cached prefix. Note that udm=14 removes Google's local results, so the footer line is often the only local signal available.

Off by default. With it on, each query also carries the results Google rendered on the page — every result exactly as shown, including its source, date, snippet and sitelinks — so Claude answers from the same evidence you can see rather than only from memory or its own searches. It travels in the message, after the prompt-cache breakpoint, so it costs nothing in cached prefix, but it is fresh input on every query: roughly 600–3,000 extra input tokens, capped at 12,000 characters. Google frequently renders destinations as abbreviated display URLs (or as opaque redirects), and those are marked as unlinkable so no answer invents an address from them.

On current SERPs the AI Overview is rendered inline in the search page, so there is no separate request to block. udm=14 is what actually stops Google generating it. It also removes knowledge panels and image packs.

Everything except the API key saves as soon as you change it.

The key is stored in this browser's extension storage and is sent only to api.anthropic.com. Effort is ignored on Haiku 4.5, which does not accept the parameter. View history.
